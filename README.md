# Cropper

Минималистичное браузерное приложение для кадрирования и базовой коррекции фотографий.

## Возможности

- загрузка JPEG, PNG и WEBP;
- свободное кадрирование и пресеты пропорций;
- базовые коррекции: Temperature, Tint, Vibrance, Saturation, Clarity, Dehaze и Levels;
- экспорт JPEG в размерах S (1000 px), M (1400 px) и L (2500 px) по большей стороне;
- обработка только в браузере: фотография не покидает устройство.

## Запуск

Откройте `index.html` в браузере. Для локальной разработки можно запустить любой статический HTTP-сервер, например:

```sh
python3 -m http.server 4173
```

Затем откройте `http://localhost:4173`.
